## Objective
Create professional visualizations and an interactive Power BI dashboard using the Sample Superstore dataset.

## Tools Used
- Python
- Matplotlib
- Seaborn
- Plotly
- Power BI Desktop

## Visualizations Created

- Bar Chart
- Scatter Plot
- Histogram
- Heatmap
- Pairplot
- Boxplot
- Interactive Plotly Chart

## Dashboard Components
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Monthly Sales Trend
- Category-wise Sales
- Top 10 Products
- State-wise Sales Map
- Category, Region, and Date Filters
