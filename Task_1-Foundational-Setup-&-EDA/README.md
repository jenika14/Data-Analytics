# Task 1: Foundational Setup & Exploratory Data Analysis (EDA)

## Objective
Perform exploratory data analysis on the Sample Superstore dataset to understand its structure, clean the data, and derive meaningful insights.

## Dataset
- Name: Sample Superstore Dataset
- Rows: 9994
- Columns: 21

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps Performed
1. Imported required libraries.
2. Loaded the dataset.
3. Checked data structure and data types.
4. Handled missing values and duplicates.
5. Converted date columns to datetime format.
6. Performed statistical analysis.
7. Explored unique categories and regions.
8. Created visualizations and correlation heatmap.
9. Documented key findings.

## Key Insights
- Technology category generated the highest sales.
- West region produced the highest profit.
- Sales data is right-skewed.
- Discounts negatively affect profits in some cases.
