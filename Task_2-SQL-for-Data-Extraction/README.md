## Objective
Master SQL queries for data extraction and business analysis using SQLite and Python.

## Dataset
- Sample Superstore Dataset
- Total Rows: 9994
- Total Columns: 21

## Tools Used

- Pandas
- SQLite
- Jupyter Notebook

- CTEs (WITH Clause)
- Window Functions (RANK)

2. Top 5 Products by Profit
3. Sales by Region
4. Profit by Category
5. Customer Spending by Segment
6. Most Sold Sub-Categories
7. Top States by Sales
8. Average Discount by Category
9. Products Above Average Sales
10. Product Ranking by Sales
